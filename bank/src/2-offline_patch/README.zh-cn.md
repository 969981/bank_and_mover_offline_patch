# Pokemon Bank 离线补丁设计

## 范围

离线补丁在不启动 Bank 服务端事务的情况下，从 `/3ds/Bank/bankdata.bin` 载入并保存数据。补丁只绕过依赖已停止服务的业务状态，不向无关系统组件伪造全局联网状态。

## 本地载入

在完整文件下载状态的 state 1 请求边界替换原流程：

1. 打开 `/3ds/Bank/bankdata.bin`，精确读取 `0xBB518` 字节。
2. 短读、格式版本不是 `2` 或盒数不是 `100` 时判定失败。
3. 使用原程序当前格式的 BankObject 载入函数处理缓冲区。
4. 按原回调语义写入结果和异步完成标志。
5. 进入原有最终成功分支，不发起后续远端事务查询。

32 字节远端事务描述不属于 bankdata，在离线会话中不使用。

## 事务性本地保存

| 拟议 Hook 边界 | 替代行为 |
|---:|---|
| `0x002B24A0` | 将完整序列化对象写入 `bankdata.tmp`，复核文件长度和实际写入量 |
| `0x002B20AC` | 卡带保存成功后，将旧文件轮换为可恢复备份，再以临时文件替换 `bankdata.bin` |
| `0x002B20E8` | 卡带保存失败后作废临时文件，保留原 `bankdata.bin` |

每个替代分支都要通过原外层状态机读取的完成字段发布结果。卡带保存及其他本地 title-save 操作保持原有顺序。

目录不存在时创建 `/3ds/Bank`；短写视为失败；所有分支都要关闭句柄；卡带保存成功以前不得覆盖最后一份有效文件。

## 已知限制

- 在找到时间戳生成逻辑前，完全离线修改可能保留旧的或为零的逐槽 64 位更新时间。
- 本地重试状态需要清理的最小集合尚未最终确认。
- 载入绕过、本地保存及共用状态修改应合并为一个 IPS，避免重叠指令地址互相覆盖。
