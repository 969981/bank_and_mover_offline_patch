# 第 3 步：离线与下载合并补丁

本工程为 Pokemon Bank v1.5 构建一个具有两种运行模式的补丁。它不会把此前两个
补丁的二进制产物直接拼接，而是在每个共用的联网与保存钩子中按模式选择行为。

## 模式选择

补丁默认进入离线模式。在标题界面按一次实体 **R** 键，会在离线模式与下载模式之间
切换；每次按键都会同步更新标题底部显示的模式。按 **A**、**START** 或触摸下屏进入
Bank 时，画面当前显示的模式会在退出标题界面的同一帧锁定，进入软件后不能再切换。

```text
标题界面（默认：离线模式）
        |
        +-- 按 R ------------------------------> 显示下载模式
        |
        +-- 再按 R ----------------------------> 显示离线模式
        |
        +-- A / START / 触摸 -----------------> 锁定当前显示模式并进入
```

标题界面的原版版本号保持不变。上屏底部原有的 HOME 返回说明也保持不变，并在其下一行
追加“当前模式”与“按 R 切换模式”的本地化文字。功能选单上屏保留原版欢迎语，
其中原本占用多行的日文、英文和韩文欢迎语使用一行等义短版；其后追加带有
“当前模式：”本地化前缀的本次会话模式说明。十个自带
语言档案均已提供对应文本。只有功能选单下屏的第一项会替换成对应模式的标签。

## 运行时文本选择

合并档案保留原版的联网、Bank 连接、保存和断开连接条目，不再全局替换。模式专用文本存放
在追加条目中，并在负责显示它的状态节点按当前会话模式选择。

| 界面状态 | 离线模式 | 下载模式 |
|---|---|---|
| 初始连接 | 本地离线连接文本 | 原版连接互联网文本 |
| 选定游戏后的连接 | 本地 Bank 数据连接文本 | 从服务器下载至 `sd:/3ds/Bank/bankdata.bin` |
| 保存 | 写入本地离线文件文本 | 若意外进入通常不可达的保存路径，则使用原版服务器保存文本 |
| 普通断开连接 | 本地断开连接文本 | 原版断开连接文本 |
| 成功捕获后的断开连接 | 不使用 | 下载完成文本，然后返回标题界面 |
| 选择语言后的断开连接 | 空文本 | 空文本 |

选定游戏后的等待界面、旋转动画和节奏音效仍由原版状态初始化、更新和析构函数管理。
补丁不会提前隐藏界面或单独停止动画/音效；本地操作完成后交还原版退出流程统一清理。

## 离线模式

离线模式保留原版的游戏软件选择、Bank 盒子与游戏保存逻辑，但将远端 Bank 数据连接
替换为第 2 步提供的、经过检查的本地文件流程。

```text
选择“使用 Pokemon Bank”
        |
        v
原版游戏软件检测与游戏选择
        |
        v
读取 sd:/3ds/Bank/bankdata.bin
        |
        +-- 有效 -----------------------------> 原版本地元数据与盒子流程
        |
        +-- 缺失或无效 -----------------------> 备份恢复，或原版首次使用创建流程
```

主文件、暂存文件、备份文件与损坏文件的处理规则见[第 2 步说明](../2-offline_patch/README.zh-cn.md)。
离线模式中的本地数据与官方服务上的数据相互独立。

## 下载模式

下载模式会保留原版的账号、联网、远端记录创建、Bank 数据下载和原版断开连接路径。
两种模式都会在本地完成独立的可选奖励状态，从而跳过里程/奖励界面，同时提供后续所需
的运行时字段。它的用途是在不进入普通 Bank 盒子会话的情况下刷新本地数据文件。

当合并钩子覆盖了原版分配准备代码时，下载模式分支会重放每一条被覆盖的分配器上下文、
分配和根对象装载指令，再从原版序列之后继续。因此官方的连接、首次创建和断开连接任务
仍会以原版方式创建。

```text
选择“下载银行数据到本地”
        |
        v
原版游戏软件检测、游戏选择与服务器下载
        |
        v
普通 Bank 下载成功回调
        |
        v
经过检查的本地暂存与提交 -> sd:/3ds/Bank/bankdata.bin
        |
        +-- 本地捕获成功 ---------------------> 跳过里程、盒子与保存界面
        |                                       -> 原版不保存断开连接
        |
        +-- 本地捕获失败 ---------------------> 不改变原版回调结果
```

只有普通 Bank 的下载路径会写入本地文件。HOME 路径不会使用捕获回调，因此不会覆盖
本地 Bank 数据。普通 Bank 捕获成功后，会显示已下载到 SD 卡并正在返回标题界面的
完成文字；下一次正常启动即进入离线模式。

## 两种模式共用的功能选单行为

两种模式下的功能选单均保持为以下可预期行为：

| 项目 | 离线模式 | 下载模式 |
|---|---|---|
| 第一项 | 使用 Pokemon Bank | 下载银行数据到本地 |
| 关于 Pokemon Bank | 原版说明界面 | 原版说明界面 |
| 确认支持代码 | 已禁用，返回功能选单 | 已禁用，返回功能选单 |
| Poke Mover/eShop | 已禁用，返回功能选单 | 已禁用，返回功能选单 |
| Pokemon HOME | 原版语言选择流程 | 原版语言选择流程 |
| 返回 | 原版行为 | 原版行为 |

HOME 项会在进入 HOME 传送状态前跳转至已有的语言选择流程，因此不会触发普通
Bank 数据的捕获逻辑。

## 源码布局

| 文件 | 作用 |
|---|---|
| `main.s` | 模式锁定、动态钩子分发、回调捕获和选单路由 |
| `combine_patch.c` | 共用的、经过检查的本地文件实现 |
| `patch_messages.py` | 重建本地化 LayeredFS 消息档案 |
| `verify_patch.py` | 检查代码范围、分支目标、IPS 封装和全部本地化文本 |
| `Makefile` | 编译、注入、生成 IPS，并写出 Luma 发布目录 |

## 编译

将 `DEVKITARM` 设为 devkitARM 安装目录，并将提取的基底代码放置到
`bank/00040000000C9B00.code`。提取的 Bank RomFS 必须位于默认的
`ROMFS_SOURCE` 路径，或者在 Make 中显式指定该变量。
受支持的解压代码镜像 SHA-256 为
`2DCE4796F54807CF8A67F1CE6297BF472D969B30ED7A7E8E25C2A6C2BDC40ABF`；
构建校验器会拒绝其他基底镜像。

```text
make -C bank/src/3-combine_patch all
```

完整的 Luma 目录将生成至：

```text
bank/release/3-combine_patch/luma/titles/00040000000C9B00/
  code.ips
  romfs/
```

将生成的 `luma` 目录复制到 SD 卡，并在 Luma 中启用游戏补丁。实际硬件使用前，
请先备份 SD 卡，并在可丢弃的存档上测试。

`all` 还会运行 `verify_patch.py`。它会检查本地实现是否仍位于被有意跳过的可选奖励
状态中、每一个修改后的 ARM 钩子是否具有预期的目标、条件码和覆盖填充、发布 IPS 回放后
是否逐字节还原构建镜像，以及十个生成的消息档案是否保留界面必需的原版标题/上屏选单
欢迎语。它还会将重放的原版分配序列与受支持的基底镜像逐项对照。

## 外部开源参考资料

- [devkitPro/libctru FS 声明](https://github.com/devkitPro/libctru/blob/master/libctru/include/3ds/services/fs.h)
  用于核对本地文件层使用的公开 FSUSER/FSFILE 接口及结果处理。

  用于核对按标题存放的 `code.ips` 与 LayeredFS 目录布局。
- [pkNX TextFile](https://github.com/kwsch/pkNX/blob/master/pkNX.Structures/Text/TextFile.cs)
  用于核对资源重建工具使用的公开消息文件编码和行表格式。

当前 Bank 二进制才是程序地址、状态转换、对象布局、文件偏移与补丁位置的依据。
上述外部资料仅用于公开的平台与文件格式接口核对。
