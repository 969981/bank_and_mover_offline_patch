# 第二步：离线补丁

## 用途与使用条件

本补丁让 Poke Mover 使用与 Pokemon Bank 共用的本地文件：
`sd:/3ds/Bank/bankdata.bin`。原版来源游戏选择、卡带读取、Pokemon 转换、确认、
来源游戏保存和断开流程继续保留。

本地必须已经存在长度恰好为 `0xBB518` 字节的当前格式 `bankdata.bin`。Poke Mover
不会创建新的银行文件。按原版获取和使用路径，用户只能通过 Pokemon Bank 取得
Poke Mover；此时银行账户及其初始银行数据已经创建。

开始新一次传送前，本地传送盒必须为空。补丁绝不会覆盖传送盒中的已有内容。

## 总体路线

```text
原版来源游戏选择
        │
        ▼
“正在连接中……” ── 在本地强制判定网络可用
        │              不创建远端连接作业
        ▼
按主机当前时间刷新“当前时间 + 999 天”的运行时离线票据
        │
        ▼
“正在连接本地离线银行数据……”（至少 2 秒）
        │
        ▼
原版卡带读取、筛选与 Pokemon 转换
        │
        ├── 第五世代合法性请求 ─────► 跳到本地后续处理
        └── 第一／二世代合法性请求 ─► 跳到本地后续处理
                                              │
                                              ▼
                                  在本地完成远端检查状态
                                              │
                                              ▼
                              载入 bankdata.bin 并合并候选
                                ├── 无效／不存在 ─► 报错
                                ├── 传送盒非空 ───► 原版消息 5；拒绝并保留原文件
                                └── 传送盒为空 ───► 原版确认界面
```

原版候选转换状态继续负责读取来源游戏、筛选记录并构造传送候选；补丁只绕过其中
两处服务器合法性请求。这两个调用位置均以当前二进制核实，并与下方引用的公开
先例交叉核对。

载入 `bankdata.bin` 前，补丁会先用原版传送槽对象保存已生成的候选，再读取并验证
完整本地银行文件。载入后的传送盒为空时，候选才会通过原版槽写入操作恢复；该操作
会同时更新每个 `0xE8` 字节槽记录及其并行标签。补丁不会用原始槽字节覆盖已有数据。

现有账户身份字段保持不变。离线票据到期时间只在运行时根据 3DS 系统时间加 999 天
计算。

## 传送保存事务

```text
用户确认传送
        │
        ▼
原版完整银行序列化（0xBB518 字节）
        │
        ▼
写入 bankdata.tmp + 设置长度 + 刷新 + 核对实际写入量
        ├── 失败 ───────────────► 中止并保留 bankdata.bin
        └── 成功
              │
              ▼
保存进度界面至少继续显示 2 秒
              │
              ▼
原版来源卡带保存
        ├── 失败 ─► 删除 bankdata.tmp ─► 保留 bin 与 bak
        └── 成功
              │
              ▼
删除旧 bak ─► bin 改名为 bak ─► tmp 改名为 bin
                                      ├── 成功 ─► 原版断开路线
                                      └── 失败 ─► 尽可能恢复 bak
```

本地暂存、提交和回滚分别替换对应的远端事务。同步暂存写入完成后，非阻塞状态机
延时会让保存界面至少显示两秒，且不会重复写入文件。只有原版来源游戏保存成功后
才会提交新银行文件。删除、改名、关闭、文件长度、实际写入量、恢复和回滚结果都会检查。

没有可传送 Pokemon 或用户取消时，补丁保留原版“不传送”路线，但会在本地完成其
最后一次服务器事务，然后进入原版断开路线。

## 显示与计时行为

LayeredFS 资源覆盖全部十种受支持语言：

- 初始互联网提示改成通用的“正在连接中……”。
- 本地银行数据提示至少显示 2 秒，随后才开始原版卡带读取与转换。
- 保存提示会表示 Pokemon 正在写入本地离线银行数据，而不是发送到服务器。
  完整本地暂存写入后，该提示至少继续显示 2 秒。
- 断开提示改成通用文本；现有的本地首阶段仍为 1.5 秒，不创建远端断开作业。

上实机前请先在模拟器中测试，并备份 `bankdata.bin`。
