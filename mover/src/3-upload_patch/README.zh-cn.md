# Poke Mover 上传补丁设计

## 范围

上传补丁通过新的 Mover 联机会话提交本地准备的 Transfer Box 修改，并保留不属于 Transfer Box 操作的其他字段。

## 联网重新上传顺序

1. 正常完成联网认证，并把服务端最新完整 Bank 文件下载为 `remote`。
2. 取得当前会话新生成的远端事务描述。
3. 比较 `base`、`local` 和 `remote` 中位于 `0x0AAF14` 的 30 个 Transfer Box 记录，以及位于 `0x0AD5FC` 的 30 个标签。
4. 将无冲突的本地记录与标签成对合并到 `remote`，保留目标 Transfer Box 修改以外的全部字段。
5. 同一 Transfer Box 槽发生冲突修改时停止上传。
6. 使用原程序的完整对象序列化、远端暂存、卡带保存和提交/回滚状态。
7. 仅在服务器提交成功后推进本地同步基线。

## 安全限制

- 服务端对 Transfer Box 以外字段的规则尚未确认。
- 第一次验证仅使用相同账户、已有备份的单槽修改以及可恢复的卡带保存。
- 过期事务描述不可复用。
